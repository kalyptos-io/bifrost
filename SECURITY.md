# Security policy

## Supported versions

Only the most recent release gets security fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it through GitHub private vulnerability reporting: go to the **Security** tab of this
repository and select **Report a vulnerability**. Include the steps to reproduce the problem, the
affected version, and the effect.

You get an acknowledgement in 72 hours and a status update in 7 days. Please give us 90 days to
release a fix before you make the problem public.
